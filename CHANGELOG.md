# Changelog

## 1.2.0
- Workout detail: explained charts (tap the "i"): heart rate linked to the map, zones, distribution, effort score, intensity, heart drift, speed, elevation profile and climb, power, km splits.
- New sport page (from Activities or Charts): trend per metric, totals, heart rate spread, records, recent sessions.
- Charts: heart rate trend, short explanation under each chart.
- Tablets and unfolded phones: side navigation rail, content centered (max 720 dp), 4 tiles per row.
- Charts only react to horizontal drags, so the page scrolls normally; keyboard no longer hides fields.
- New permissions: speed and power (tap "Allow access" in Settings once).

## 1.1.0
- Material 3 Expressive look: cookie-shaped sport icons, bigger rounded shapes, connected list groups, collapsing large top bars.
- New transitions (scale + fade for tabs, shared-axis style for details), bouncy press effect, staggered entrance.
- Activities: sport summary cards (count + total time) that filter the list.
- Charts: breakdown by sport and records.
- Workout detail: kilometer splits, spinning sport icon.
- Home: week totals and day streak.

## 1.0.0
- New native Kotlin app (Jetpack Compose, Material 3).
- Health Connect: workouts, GPS routes, heart rate, steps, sleep, weight.
- Duplicates from several apps are merged into one activity.
- Intervals.icu as a backup source for GPS routes.
- English and French.
